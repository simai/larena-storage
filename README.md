# Larena Storage

Universal dynamic data storage layer for typed schemas, records, lists, query boundaries, persistence profiles, validation pipelines and portable SitePack-compatible data models.

Current implementation state: partial data/content foundation runtime. The package has an in-memory runtime slice plus a baseline Laravel database persistence/access/audit integration slice. Production schema migrations, encryption policy and SitePack portability are still separate launch records.

Canonical specifications are in `simai/larena-specs`.

Developer documentation starts at `docs/developer/README.md`.
